A tiny stack VM for make.fun's ISA v1: 32-bit wrapping integers, a 256-value
stack, branches, calls, 256 words of memory, input/output, and all ten traps
with their exact exit codes. Node 22 stdlib only, deterministic, one run
answers all 40 instances (`node main.ts`).
